# Radar Tech

Uma reportagem por dia sobre governança de TI, GRC, gestão de serviços, ITIL, COBIT, ISO 27001, segurança da informação e inteligência artificial.

Cada edição traz fatos verificados, com fonte, e explica por que o assunto importa para quem trabalha com tecnologia. Textos escritos com apoio de IA e revisados antes de publicar.

## Edições

As edições ficam na pasta [`edicoes/`](edicoes/), uma por dia.
